Database Filter & Scope Engine

Apply WHERE conditions with GROUP BY aggregation to dynamically scope the dataset

Generated SQL
SELECT city_name, COUNT(*) AS record_count,
  AVG(temperature_c) AS avg_temp,
  AVG(humidity_pct)  AS avg_humidity
FROM center_hourly_weather_data
INNER JOIN cities USING (city_id)
WHERE temperature_c > 20
GROUP BY city_name
ORDER BY avg_temp DESC
LIMIT 15000;
